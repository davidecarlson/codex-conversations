A record of Codex conversations, actions, measured results, and limitations.

Each conversation has a dated Markdown log and supporting evidence where available. Credentials, SSH keys, model weights, and caches must never be committed.

## Adding a conversation

Create `conversations/YYYY-MM-DD-topic.md` with the user's requests, the assistant's responses, actions performed, results, and any unresolved limitations. Store small supporting files in `results/YYYY-MM-DD/` and link them from the log. Distinguish direct measurements from inferred explanations.
